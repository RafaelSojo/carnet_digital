## 1.Abrir el directorio principal del proyecto en VSCode.


## 2.Abrir la terminal y ejecutar el comando en los directorios /frontend y /backend
```bash 
npm install
```
---

## 3.Cambiar el String de conexión a la BD en el archivo .env de /backend en caso de ser necesario (La BD actua es local de MYSQL).
---


## 4.Abrir terminal y ejecutar en en /frontend y /backend
```bash 
npm run dev
```
---
